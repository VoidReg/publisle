# @publisle/cli-research

Optional Publisle Research profile CLI plugin: journal export, bibliography acquisition, and compiler tooling.

Requires Node.js 24 or later. Framework adapters also require their declared peer dependencies.
This repository is in beta; `0.0.0` is the unreleased workspace version.
Frozen contract version integers are independent of npm package versions.

- [Core standard](https://github.com/VoidReg/publisle/blob/main/docs/standards/README.md)
- [Quickstart and package usage](https://github.com/VoidReg/publisle#readme)
- [Distribution and release checklist](https://github.com/VoidReg/publisle/blob/main/docs/guides/releases.md)
- [Research export guide](https://github.com/VoidReg/publisle/blob/main/docs/guides/journal-export.md)

Research tooling is optional and is excluded from Core-only installations. Read any
included `NOTICE.md` for third-party licensing obligations.
